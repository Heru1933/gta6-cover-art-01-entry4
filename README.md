Neon Vice turns your own photos into poster-style cover art. Drop in a handful of pictures, pick one of six multi-panel layouts (Mosaic, Poster, Quad, Trio, Duo, Solo) framed by cream keylines and panel shadows, and grade the whole cover in one click — Vice Sunset, Neon Night, Golden Hour, Noir or Clean — with optional film grain, vignette and a striped retro-sun overlay. Each panel can be selected, panned by dragging, zoomed, cycled through the photo pool, switched between Fill and Fit, re-centred, or swapped for a drawn sunset scene. Poster lettering is set in the vendored Anton or Bebas Neue typefaces with auto-fit sizing and top or bottom placement, and the finished cover exports as a PNG at 1080×1080, 1080×1350 or 1920×1080 — the on-screen preview is drawn at the exact export resolution, so what you see is the file you get. Everything runs locally and offline: no uploads, no watermark, no Rockstar assets.

## Run it

```
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `app/index.html` in a browser to use the maker (or run `node serve.ts` for a local preview server).
